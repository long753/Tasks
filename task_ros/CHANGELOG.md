# 更新记录

- 全局规划改为自动读取场景 `dock_marker` 的位置和朝向，等待 AMCL 与规划器就绪后请求一次路径；目标和成功路径以保留消息发布，RViz 无需手动输入目标，晚启动也可显示。
- 桌台顺时针旋转 90° 并移至 `(3, -2.2)`，停靠点移至北侧 `(3, -1.3)`、朝南；同步调整托盘与物块、支持旋转后的桌面规划投影，并用实际激光刷新受影响地图区域。
- 新增 `scripts/planning.launch.py`，组合自动 AMCL 定位与 NavFn A* 全局规划；RViz 目标通过 `ComputePathToPose` 生成 `/plan`，不接入速度控制。
- 规划使用独立的工作台投影地图和静态膨胀代价地图，保留原定位地图；采用收拢机械臂的保守圆形轮廓，拒绝未知、障碍和越界目标，不替换不安全目标。
- AMCL 改为自动从场景 `start_marker` 初始化，无需手动设置初始位姿；机器人生成与定位共享起点 XY/yaw，避免坐标配置不一致。初始化后继续由 AMCL 跟踪运动，不持续使用真值覆盖定位。
- 新增已知地图定位入口 `scripts/localization.launch.py`、AMCL 参数和 RViz 配置；仅运行地图服务器、AMCL、生命周期管理和可选可视化，手动设置初始位姿，不使用 Gazebo 真值定位或发布底盘速度。
- 仿真入口重命名为 `scripts/world.launch.py`，迁移维护说明与移动障碍模型中的引用，不保留旧名入口。
- 建图节点不再管理 RViz 子进程和临时保存目录；退出改为 Python 中断与 finally 清理，移除自定义停止标志。新增 `scripts/mapping.launch.py`，用 `rviz:=false` 关闭可视化；栅格算法拆为投影、射线离散化和证据更新，保留时间同步及地图格式。
- 移动障碍从注释块提取为独立模型，由 `moving_obstacle:=true` 统一启用模型、桥接和驱动，默认保持停用；启动文件和机器人模型增加职责分段。
- 修正 `auto_pkg` 的导航入口，移除空抓放节点及其入口，补齐包说明。
- 改用 Ubuntu 系统 Python 启动 ROS 2 仿真，移除项目的 uv 启动脚本、依赖配置和锁文件。
